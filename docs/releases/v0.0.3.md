# Commonspace v0.0.3

Commonspace improves workspace recovery, desktop navigation, and native runtime compatibility. The project now lives at [commonspaceai/commonspace](https://github.com/commonspaceai/commonspace).

## Workspace reliability

- Recover saved conversations from the rollback backup when the primary state file is missing or invalid.
- Prevent overlapping workspace imports and conflicting mutations during restoration.
- Clean up orphaned native agent processes and preserve accepted work during recovery.
- Keep settings and pin drafts after failed saves, and preserve settings edits during live refreshes.
- Keep the selected conversation when a delayed send completes after navigation.
- Apply native compaction events to the browser view.
- Preserve authored message text in exports while keeping managed private metadata out of archives.

## Desktop improvements

- Find Projects directly in search and open the exact matching reply.
- Retry failed searches without losing the query or filters, with announced search status.
- Keep stale search results unavailable while a replacement request runs.
- Restore keyboard focus when closing settings, reordering queued follow-ups, or removing queued items.
- Return to Inbox when a selected destination disappears during refresh.
- Apply Light/Dark/System appearance to native browser controls and preserve the selected mode across reloads.

## Runtime, packaging, and maintenance

- Harden native runtime compatibility checks and read-only capability inspection.
- Add Windows source, browser, and foreground-package checks, including clean installation of the same Linux-built tarball used for npm publication.
- Refresh the Claude Code and Codex ACP bridges, OpenCode fixture, UI dependencies, TypeScript, ESLint, and GitHub Actions dependencies.
- Update the Commonspace logo, repository links, npm README links, star chart, and npm trusted publishing for the new organization.

## Compatibility and installation

```bash
npx --yes commonspace@0.0.3
```

The npm package requires Node.js 22 or newer. Source development requires Node.js 22.13+ or 24+.

Gemini's longer-history session replay and Pi's MCP transport remain limited by their native runtimes. Windows headless checks do not establish interactive Ctrl+C, native folder dialogs, notifications, or authenticated agent support. Commonspace does not install a Windows service. See the [support matrix](https://github.com/commonspaceai/commonspace/blob/main/docs/start/support.md), [desktop guide](https://github.com/commonspaceai/commonspace/blob/main/docs/guides/desktop-usage.md), and [Windows validation guide](https://github.com/commonspaceai/commonspace/blob/main/docs/guides/windows-validation.md) for the tested boundaries.
